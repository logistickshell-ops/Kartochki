# Карточки — интерактивные задания

Русскоязычное статическое веб-приложение для спокойных занятий с детьми. Внутри есть семь тематических наборов и 14 демонстрационных карточек. Ребёнок отвечает касанием или показывает выбор взрослому; устная речь не обязательна. В приложении **нет админки**: содержание карточек меняется в исходном файле через GitHub.

## Быстрый запуск

Требуются Node.js 22.12+ и pnpm 11.25.0.

```bash
corepack enable
pnpm install
pnpm dev
```

Production-сборка:

```bash
pnpm install --frozen-lockfile
pnpm build
```

Статический сайт собирается в `dist/`.

## Как добавлять и менять задания на GitHub

1. Откройте репозиторий в GitHub.
2. Выберите файл **`src/content.ts`** и нажмите кнопку с карандашом **Edit this file**.
3. Найдите нужный тематический блок: `day-night`, `hygiene`, `clothes-weather`, `food`, `home`, `transport` или `feelings`.
4. Скопируйте одну карточку из этого блока, вставьте её внутрь того же массива и поменяйте текст и варианты ответа.
5. У каждой карточки должен быть новый уникальный `id`. `correctOptionId` должен точно совпадать с `id` правильного варианта в `options`.
6. Нажмите **Commit changes**. Если репозиторий подключён к Render с авто-деплоем, сайт пересоберётся после commit. Иначе запустите Deploy вручную в Render.

Пример новой карточки в блоке `day-night`:

```ts
{
  id: 'dn-moon', // уникальный ID
  topicId: 'day-night',
  icon: '🌙',
  prompt: 'Что можно увидеть на ночном небе?',
  instruction: 'Выбери одну карточку.',
  hint: 'Посмотри на небо.',
  options: [
    option('moon', 'Луну', '🌙'),
    option('sun', 'Солнце', '☀️'),
  ],
  correctOptionId: 'moon',
},
```

Не удаляйте запятую после карточки и не переименовывайте поля. Держите инструкции короткими, варианты однозначными, а обратную связь — спокойной. Чтобы завести новую тему, кроме карточек потребуется также добавить описание темы в `src/data.ts` и расширить `TopicId` в `src/types.ts`.

## GitHub → Render Static Site

1. Отправьте этот проект в ваш GitHub-репозиторий и подключите его в Render как **Static Site**.
2. Выберите ветку с кодом, например `main`.
3. Укажите **Build Command**: `pnpm install --frozen-lockfile && pnpm build`.
4. Укажите **Publish Directory**: `dist`.
5. Дождитесь HTTPS-домена Render и проверьте сайт на телефоне.

Внутренняя навигация использует hash-маршруты `/#/...`; специальные правила переписывания URL на Render не нужны.

## Telegram Mini App

`index.html` подключает Telegram WebApp SDK. При запуске внутри Telegram приложение вызывает `ready()` и `expand()`; вне Telegram сайт тоже работает.

После публикации сайта:

1. Откройте BotFather и выберите или создайте бота.
2. Настройте для бота Main Mini App либо кнопку запуска Web App.
3. Укажите HTTPS URL Render и проверьте запуск на телефоне.

Username бота, short name Mini App и финальный домен нужно задать в учётных записях владельца после публикации. Бот автоматически не создаётся.

## Что хранится локально

Задания являются частью исходного кода и обновляются при следующей публикации с GitHub. Прогресс занятий, текущая карточка, режим сопровождающего и отметки чек-листа сохраняются в `localStorage` текущего браузера и между устройствами не синхронизируются. Приложение не собирает профили детей и не требует аккаунтов.
