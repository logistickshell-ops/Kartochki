# Чек-лист сервиса «Карточки»

## 1. Анализ материала и целей
- [ ] Определить одно умение для карточки: узнать, выбрать, соотнести, попросить или выполнить шаг.
- [ ] Учитывать понимание речи, зрение, моторику, внимание, утомляемость и привычные способы коммуникации ребёнка.
- [ ] Использовать знакомые слова и ситуации; проверять задания на неоднозначность.
- [ ] Обсудить бытовые и безопасностные формулировки со специалистом или близкими ребёнка.

## 2. Подготовка карточки
- [ ] Оставить одну короткую инструкцию и небольшой выбор ответов.
- [ ] Проверить, что правильный ответ однозначен в описанной ситуации.
- [ ] Не требовать устного ответа; принять касание или ответ, указанный взглядом/жестом через взрослого.
- [ ] Добавить подсказку и спокойную фразу для повторной попытки.
- [ ] Использовать знакомые изображения/символы и не перегружать экран.

## 3. Ручное добавление через GitHub
- [ ] Открыть `src/content.ts` в репозитории и выбрать **Edit this file**.
- [ ] Найти блок нужной темы: `day-night`, `hygiene`, `clothes-weather`, `food`, `home`, `transport`, `feelings`, `seasons`, `week`, `animals` или `weather`.
- [ ] Скопировать соседний объект карточки и вставить в этот же тематический массив.
- [ ] Задать новый уникальный `id`; сохранить правильный `topicId` и используемые поля.
- [ ] Убедиться, что `correctOptionId` совпадает с одним из `options[].id`.
- [ ] Проверить запятые и скобки, затем выбрать **Commit changes**.
- [ ] Если создаёте новую тему, дополнительно изменить `src/types.ts` и `src/data.ts`.

## 4. Проверка карточки и занятия
- [ ] Проверить правильный и неверный ответ, повтор инструкции, подсказку и переход дальше.
- [ ] Пройти тему до экрана завершения, затем повторить занятие.
- [ ] Посмотреть, как работает режим взрослого и пропуск карточки.
- [ ] Проверить отображение на телефоне, планшете, компьютере и в Telegram WebView.
- [ ] Убедиться, что значок зубной щётки виден: он встроен как SVG и не зависит от поддержки эмодзи шрифтом устройства.
- [ ] Попросить специалиста/близкого проверить понятность и сенсорный комфорт.

## 5. Доступность и приватность
- [ ] Проверить крупные кнопки, контраст, видимый фокус и управление клавиатурой.
- [ ] Убедиться, что анимация не мигает, а звук включается только по запросу.
- [ ] Не добавлять в карточки фамилии, диагнозы, фото или другие сведения конкретного ребёнка.
- [ ] Помнить, что прогресс и отметки чек-листа остаются только в текущем браузере.

## 6. GitHub → Render Static Site
- [ ] Не размещать в публичном GitHub-репозитории секреты и личные данные.
- [ ] Подключить репозиторий и ветку (например, `main`) как **Render Static Site**.
- [ ] Указать Build Command `pnpm install --frozen-lockfile && pnpm build`.
- [ ] Указать Publish Directory `dist`.
- [ ] Дождаться успешной HTTPS-публикации; проверить её на телефоне.
- [ ] После commit в GitHub убедиться, что Render пересобрал сайт и новые карточки появились.

## 7. Telegram Mini App
- [ ] Настроить Main Mini App или кнопку запуска в BotFather.
- [ ] Указать HTTPS URL опубликованного Render-сайта.
- [ ] Проверить запуск из чата бота на телефоне и работу безопасных отступов.
- [ ] После смены домена обновить URL в настройках бота.
- [ ] Если появится серверная авторизация, валидировать Telegram `initData` только на сервере.

## Архитектурная граница
Задания редактируются в `src/content.ts` и попадают пользователям после сборки/публикации из GitHub. Веб-приложение не содержит админки и не позволяет менять каталог из браузера. Локально хранятся только учебный прогресс и отметки чек-листа.
